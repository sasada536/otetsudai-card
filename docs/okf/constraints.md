# 既知の制約

## 残存する制約

| # | 内容 | 影響度 | 備考 |
| --- | --- | --- | --- |
| 1 | Notion のプロパティ名が日本語でハードコードされている。列名を変更すると該当タスクが取得できない | 中 | 0 件になった場合は警告が出る |
| 2 | 「かならずもらえる」金額は `FIXED_ALLOWANCE` 定数であり、Notion からは変更できない | 中 | 変更にはコード修正が必要 |
| 3 | 6 色しかないため、タスク数が多いと同じ色が複数回現れる | 低 | `POSTER_COLORS` に色を追加すれば緩和できる |
| 4 | チャレンジタスクが 13 件以上だと 1 部が 2 ページになる（2 部で 4 ページ） | 低 | 意図した挙動 |
| 5 | 自動テストが無く、リグレッションは手動確認に依存する | 低 | `--sample` での目視が唯一の検証手段 |

## 意図的にそうしている点

| 内容 | 理由 |
| --- | --- |
| タスクが多いとき、計算欄だけを 2 ページ目に送る | 表を途中で切るより読みやすいため。12 件以下なら従来どおり 1 ページに収まる |
| 日付が 1〜31 の固定で、実際の月の日数を考慮しない | 対象月は手書き記入のため。実害は「使わない列が残る」ことのみ |
| Google Fonts をオンライン参照している | フォントを埋め込むと数 MB になるため。オフラインでは既定フォントで表示される |
| 件数超過時にレイアウトを自動調整しない | 警告を出して人間が判断する方針。自動縮小は可読性を損なうため |
| `--sample` を自動フォールバックにしない | CI の設定漏れ時に架空データが公開されるのを防ぐため |
| 自動テストを置いていない | 出力が印刷物であり、正しさの判定が目視に依存するため |

## 解消済み

| 内容 | 対応 |
| --- | --- |
| HTML エスケープをしておらず、`<` `>` `&` でマークアップが壊れた | 全ての Notion 由来の値を `esc()` 経由に変更 |
| API エラーがトレースバックで落ちた | `fail_with_api_error()` で原因別のメッセージを表示 |
| 第三者が認証情報なしに再現できなかった | `--sample` とサンプルデータを追加 |
| 機械可読なデータを出力していなかった | [tasks.json](./output-tasks-json.md) を追加 |
| 生成物に来歴が無かった | メタタグと画面注記を追加 |
| `.gitignore` が無く `output/` を誤コミットしうる | `.gitignore` を追加 |
| ライセンス未設定で第三者が再利用できなかった | MIT License を設定 |
| ポスターの色・アイコンが並び順依存で、1 件追加すると以降が全てずれた | タスク名から決まる方式に変更（[きほんポスター](./output-basic-poster.md)） |
