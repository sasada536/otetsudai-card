# 公開ポリシー

**このリポジトリは GitHub 上で公開運用している。コミット・プッシュする内容はすべて、
全世界から永続的に閲覧できる前提で扱う。** git の履歴は後から消しにくいため、
「入れてしまってから消す」ではなく「最初から入れない」で守る。

このポリシーは人間にも AI エージェントにも等しく適用される。同じ内容が
`CLAUDE.md` にも最優先ルールとして記載されている。

## 絶対にコミットしてはいけないもの

- `NOTION_TOKEN`、API キー、各種シークレット（GitHub Actions Secrets 経由でのみ渡す）
- `NOTION_DATABASE_ID`（データベースを特定できる識別子。生成物にも埋め込まない）
- 実在の家族の氏名・学校名・住所・写真・生活パターンが推測できる情報
- `output/` の生成物（実データを含むため。`.gitignore` 済み）
- 上記が写り込んだスクリーンショットやログの貼り付け

## 守るべきこと

- サンプルデータ（[タスクデータモデル](./task-model.md)）は**架空の内容のみ**。
  実在のタスクをコピーしない
- 新しい出力項目・新しいファイルを追加するときは、**公開して問題ないかを必ず確認してから**追加する
- 迷ったら入れない。判断がつかない場合はユーザーに確認する
- 公開前チェック `scripts/check_public_output.py` を弱めたり、迂回したりしない

## 公開範囲の切り分け

| 区分 | 対象 |
| --- | --- |
| 公開する | コード、ドキュメント、架空のサンプルデータ、生成された HTML と `tasks.json` |
| 公開しない | Notion データベース本体、`NOTION_TOKEN`、`NOTION_DATABASE_ID` |

**オープンにしているのはツールと生成物であって、入力データではない。**
ただし生成物には実際のタスク内容が入るため、Notion に何を書くかの段階で判断する。

## 技術的な担保

| 仕組み | 役割 |
| --- | --- |
| `.gitignore` | `output/` の誤コミットを防ぐ |
| `scripts/check_public_output.py` | 公開前に秘密情報の混入を検出して停止する |
| `tasks.json` の設計 | DB 識別子を出力に含めない |
| GitHub Secret scanning | Public リポジトリでは GitHub 側でも自動検出が働く |

チェックは最後の関門であり、免罪符ではない。混入させないことが第一。

## 補足：コミットのメタデータ

コミットの author 名とメールアドレスも公開される。これは GitHub アカウントの設定に
属するため本リポジトリの管理外だが、伏せたい場合は GitHub の noreply アドレス設定を使う。
