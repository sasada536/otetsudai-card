# きほんポスター (basic_tasks_poster.html)

[基本タスク](./task-model.md) を載せる A4 縦の掲示用ポスター。
`build_basic_poster_html(basic_tasks, prov)` が生成する。

## 構成

- ヘッダー：🏠 /「きほんのお手伝い」/「これは毎日やること。家族の一員としての大事なしごと。」
- 記入欄：「なまえ」（50mm 下線）
- タスクカードのリスト
- フッター：⭐ ⭐ ⭐ とチャレンジへの誘導文

用紙は幅 190mm × 最小高さ 270mm（印刷時は `width: 100%` / `min-height: 100vh`）。
各カードは「アイコン（28pt）＋ タスク名（14pt / 900）＋ 備考（8.5pt）」で、左端に 5px の
カラーボーダーが付く。

## アイコンの選び方

`pick_icon(name)` が **タスク名に含まれる語** からアイコンを決める。`ICON_RULES` を
上から順に判定し、最初に一致したものを使う。どれにも当てはまらない場合は
`FALLBACK_ICONS`（10 種）から名前のハッシュで選ぶ。

| タスク名の例 | アイコン |
| --- | --- |
| くつをそろえる | 👟 |
| くつしたをそろえる | 🧦 |
| 食器をながしに運ぶ | 🍽️ |
| ぬいだ服をカゴに入れる | 👕 |
| せんたくものをたたむ | 🧺 |
| はみがきをする | 🪥 |
| おふろそうじ | 🛁 |
| テーブルをふく | 🧽 |
| ゴミ出しをてつだう | 🗑️ |
| ランドセルの中を出す | 🎒 |
| おもちゃをかたづける | 🧸 |

> **`ICON_RULES` を編集するときの注意**
> かな表記が重なる語があるため、**具体的な語を先に置く**こと。
> 例：`くつした` は `くつ` より前、`テーブル` は `ふく` より前に置く必要がある
> （「テーブルをふく」が「服」の規則に吸われないようにするため）。

## 色の決め方

`pick_colors(names)` が色を割り当てる。色は **タスク名の SHA-256 から決まる**ため、
タスクを追加・削除・並べ替えしても**他のタスクの色は変わらない**。

Python 組み込みの `hash()` は実行ごとに変わる（`PYTHONHASHSEED`）ため使えない。
SHA-256 を使うのは暗号目的ではなく、実行をまたいで同じ値を得るためだけ。

ただし同じ色が上下に隣り合うと見づらいため、その場合だけ次の色にずらす。
このため、**隣り合ったタスクの色は直前のタスクに影響されることがある**。

色は 6 種類。

| クラス | 背景 | ボーダー |
| --- | --- | --- |
| `c1` | `#fff7ed` | `#fb923c`（オレンジ） |
| `c2` | `#fdf4ff` | `#c084fc`（紫） |
| `c3` | `#f0fdf4` | `#4ade80`（緑） |
| `c4` | `#eff6ff` | `#60a5fa`（青） |
| `c5` | `#fff1f2` | `#fb7185`（ピンク） |
| `c6` | `#fefce8` | `#facc15`（黄） |

6 色しかないため、タスク数が多いと同じ色が複数回現れる。順番に循環させていた旧実装と
違い均等には散らないので、色の偏りが気になる場合は `POSTER_COLORS` に色を追加する。
