# タスクが出てこないときの対応

Notion に書いたタスクが紙に出ない場合、**エラーではなく無言で捨てられている**可能性が高い。
[Notion データベース](../notion-database.md) の採否ルールを踏まえて上から順に確認する。

## 1. 実行ログの件数を見る

```
基本タスク: 6件, チャレンジタスク: 7件
```

期待より少なければ、下記のいずれかで捨てられている。0 件のときは警告も出る。

## 2. 「タイプ」を確認する

最も多い原因。`基本` `チャレンジ` の**どちらでもない値**（空欄、表記ゆれ、
全角半角の違い、前後の空白）だと、その行は捨てられる。

- Notion のセレクト選択肢が `基本` `チャレンジ` のままか
- 選択肢名をリネームしていないか

## 3. 「タスク名」が空でないか確認する

`タスク名` が空の行は捨てられる。見た目は入力済みでも、別のプロパティに書いていることがある。

## 4. プロパティ名そのものを確認する

コードは日本語のプロパティ名をハードコードしている。以下と 1 文字でも違うと読めない。

`タスク名` / `タイプ` / `難易度` / `単価（円）` / `備考`

特に `単価（円）` の括弧は**全角**である点に注意。

## 5. インテグレーションの接続を確認する

DB 自体が読めていない場合は `HTTP 404` で止まる。Notion で「...」→「コネクト」から
インテグレーションが接続されているかを見る。

## 6. 手元で再現する

Notion 側に原因が見つからない場合は、ローカルで動かして切り分ける。

```bash
# サンプルデータで動くなら、コードではなくNotion側の問題
python generate.py --sample
```

## 直し方

原因が Notion 側なら、直してからワークフローを再実行するだけでよい
（[カードを更新して印刷する](./run-generation.md)）。

プロパティ名を変えたい場合は、`generate.py` の `load_tasks()` を合わせて修正する必要がある。
